# Email Search Cheat Sheets for IT Admins and Investigators

Search operators save hours when a mailbox holds thousands of messages. This repo collects short cheat sheets for Gmail, Outlook and PDF search, with the exact syntax and a sample query next to every operator.

*Last reviewed 19 November 2026.*

> We are the team behind MailXaminer at SysTools. One guide links to a related article on our site and we mark it. Nothing here is legal advice.

## Guides

- [Gmail Search Operators Cheat Sheet](gmail-operators.md)

## How to Use These Guides

Copy a sample query into the search box and change the names, dates and file types to match your mailbox. Every guide names its official source at the bottom so you can check the syntax yourself.
